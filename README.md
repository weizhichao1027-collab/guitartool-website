# GuitarTool Marketing Site

GuitarTool 的官方中文营销网站，展示调音器、节拍器、吉他与尤克里里和弦库、主屏幕小组件和 Apple Watch 体验。

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The site is built with Next.js-compatible Vinext and deployed with OpenAI Sites.
